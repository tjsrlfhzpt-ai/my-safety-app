# SAFE DUCKY (세이프더키)

> 안전한 오늘, 더 좋은 내일

휴대폰에서 쓰는 기기 전용 산업안전 관리 앱입니다.

휴대폰에서 산업안전 기록을 작성·확인하고, 인쇄하거나 엑셀로 내보내는 앱입니다.

## 이 앱의 성격

- **서버가 없습니다.** 로그인도, 회원가입도, 동기화도 없습니다.
- 모든 데이터는 **이 기기의 브라우저 저장소**에만 저장됩니다.
- 설치 즉시 사용할 수 있고, 인터넷이 끊겨도 동작합니다.

## ⚠️ 가장 중요한 것 — 백업

데이터가 이 기기에만 있으므로 **백업이 유일한 복구 수단**입니다.

- 브라우저 데이터를 지우거나 앱을 삭제하면 **복구할 방법이 없습니다.**
- **iOS(아이폰)에서는 홈 화면에 추가하지 않으면, 7일간 쓰지 않았을 때
  저장 데이터가 자동으로 삭제될 수 있습니다.** 반드시 홈 화면에 추가해서 쓰세요.
- 위험성평가·안전교육 기록 등은 산업안전보건법상 보존기간이 있습니다.
  정기적으로 `설정 → 백업 다운로드`로 파일을 받아 별도 보관하세요.

백업을 7일 이상 안 하면 첫 화면에 경고가 계속 표시됩니다.

## 사용 방법

1. 브라우저로 접속
2. **홈 화면에 추가** (iOS: 공유 → 홈 화면에 추가 / Android: 메뉴 → 앱 설치)
3. 바로 사용 시작

## 주요 기능

| 분류 | 내용 |
|---|---|
| 기록 | 위험성평가, 개선조치(CAPA), 사고·아차사고, TBM, 안전교육 |
| 관리 | 법정선임, 협력업체, 보호구 지급, 건강관리, MSDS, 작업허가서(PTW) |
| 현장 | 현장 사진 촬영·표시, 음성 입력, QR 스캔, 전자서명, 날씨 |
| 출력 | 인쇄(공식 서식), 엑셀 내보내기, JSON 백업·복원 |
| 기타 | 법정 체크리스트, 변경 이력(감사로그), AI 비서(선택) |

## 선택 기능 (API 키 필요)

아래 두 가지는 직접 키를 넣어야 동작하며, 그때만 외부로 정보가 전달됩니다.
키는 이 브라우저에만 저장되고 백업 파일에도 포함되지 않습니다.

- **AI 비서**: Google Gemini 키 (aistudio.google.com에서 무료 발급)
- **날씨**: OpenWeatherMap 키

> AI 비서에 건강진단 기록 등 민감한 내용을 넣지 마세요. 질문 내용이 Google로 전송됩니다.
