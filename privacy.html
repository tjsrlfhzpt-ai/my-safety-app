SAFE DUCKY(세이프더키) 개인정보처리방침

시행일: 2026-09-12 · 최종 수정일: 2026-09-12

SAFE DUCKY(이하 "이 앱")는 산업안전 기록(위험성평가·안전점검·교육·건강관리 등)을 개인 휴대폰에서 작성·보관·출력하기 위한 애플리케이션입니다. 이 앱은 서버 없이 이용자의 기기에서만 동작하며, 개발자(운영자)는 이용자가 입력한 안전관리 기록 데이터를 전송받거나 열람할 수 없습니다. 이 방침은 이 앱이 실제로 처리하는 정보만을 기준으로 작성되었습니다.

1. 이 앱이 만들고 저장하는 데이터

위험성평가, 안전점검, 사고·아차사고 기록, TBM, 안전교육, 건강관리, MSDS, 작업허가서, 협력업체, 법정선임 등 이용자가 앱에 직접 입력하는 모든 기록은 이용자 기기의 브라우저 저장소(localStorage)에만 저장됩니다. 이 데이터는 인터넷으로 전송되지 않으며, 개발자를 포함한 어떤 제3자도 접근할 수 없습니다.

⚠️ 데이터가 이 기기에만 있으므로, 브라우저 데이터를 지우거나 앱을 삭제하면 복구할 수 없습니다. 이용자는 [설정 → 백업 다운로드] 기능으로 주기적으로 자신의 데이터를 직접 백업해야 합니다.

2. 외부로 전송되는 정보 (선택 기능에 한함)

아래 두 기능은 이용자가 직접 자신의 API 키를 입력해야만 동작하며, 사용하지 않으면 어떤 정보도 외부로 전송되지 않습니다.

기능전송되는 정보전송 대상비고
AI 비서이용자가 입력한 질문/보고서 초안 텍스트Google Gemini API (이용자 본인의 API 키로 직접 호출)개발자 서버를 거치지 않고 이용자 기기 → Google로 직접 전송됨. 건강진단 기록 등 민감한 내용은 입력하지 않을 것을 권장
날씨 위젯기기의 위치 좌표(GPS)OpenWeatherMap API (이용자 본인의 API 키로 직접 호출)현재 날씨 표시 목적으로만 사용

두 기능 모두 API 키는 이용자 기기에만 저장되며, 백업 파일에도 포함되지 않습니다.

3. 수집하지 않는 정보

이 앱은 회원가입·로그인 기능이 없어 이름·전화번호·이메일 등 계정 정보를 수집하지 않습니다. 광고 SDK, 분석(애널리틱스)·추적 도구를 포함하지 않으며, 이용자의 기기 사용 행태를 수집하지 않습니다.

4. 카메라·사진·위치·마이크 접근 권한

현장 사진 첨부 기능은 이용자가 촬영하거나 선택한 사진을 이용자 기기 저장소에만 보관하며 외부로 전송하지 않습니다. QR코드 스캔 기능을 사용할 때는 카메라 화면을 실시간으로 보여주기 위해 카메라가 켜지지만, 촬영된 영상 자체를 저장하거나 전송하지는 않습니다.

위치(GPS) 권한은 두 가지 목적으로 쓰입니다. ① 날씨 위젯 사용 시 OpenWeatherMap으로 좌표가 전송됩니다(위 2번 표 참고). ② 위험성평가·안전점검·긴급신고 등 기록에 "위치 기록" 버튼을 눌렀을 때, 좌표를 기록에 첨부하기 위해 사용되며 이 좌표는 외부로 전송되지 않고 이용자 기기에만 저장됩니다.

음성입력 기능은 브라우저에 내장된 음성인식 기능(Web Speech API)을 사용합니다. 이 기능은 이 앱이 아니라 이용자가 쓰는 브라우저(예: Android Chrome)가 자체적으로 처리하며, 브라우저 종류에 따라 음성이 브라우저 제조사(예: Google)의 음성인식 서버로 전송될 수 있습니다. 이는 이 앱이 별도로 수집·저장하는 것이 아니라 브라우저가 제공하는 표준 기능이 동작하는 방식입니다.

위 권한들은 모두 해당 기능을 실제로 사용할 때만 요청되며, 이용자가 기기 설정에서 언제든 끌 수 있습니다.

5. 데이터 보관 기간 및 삭제

모든 기록은 이용자가 직접 삭제하거나, 앱을 제거하거나, 브라우저 저장소를 초기화할 때까지 이용자 기기에 보관됩니다. 개발자는 이 데이터를 원격으로 삭제하거나 열람할 방법이 없습니다. 산업안전보건법령상 일부 기록(위험성평가·교육 등)은 법정 보존기간이 있으므로, 삭제 전 백업을 권장합니다.

6. 만 14세 미만 아동 대상 서비스가 아닙니다

이 앱은 사업장의 안전관리자·근로자를 위한 업무용 도구로, 만 14세 미만 아동을 대상으로 하지 않습니다.
